hisaishi

keyless memory gateway

The keyless staging, pinning and batch gateway for MemoryOverEth: it prepares memory commitments for signing and never holds a wallet key.

Runs as a local Node + SQLite process or as a Cloudflare Worker, with one shared HTTP contract and one shared contract suite.
